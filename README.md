# FBD-120 Fluid Bed Dryer Simulator

محاكاة تفاعلية كاملة لآلة التجفيف بنظام الطبقة السائلة FBD-120

## نظرة عامة

هذا المشروع عبارة عن محاكاة ويب تفاعلية لآلة التجفيف الصناعية FBD-120، مصممة لتوفير تجربة واقعية للتدريب والاختبار بدون الحاجة إلى الأجهزة الفعلية.

## الميزات

- ✅ **محاكاة فيزيائية واقعية** للحرارة والضغط
- ✅ **رسوم متحركة احترافية** للآلة والجزيئات (60 FPS)
- ✅ **نظام إنذارات متقدم** مع سجل تاريخي وأصوات تنبيه
- ✅ **وضع تحكم يدوي** كامل لجميع المكونات
- ✅ **نظام وصفات** جاهزة لأنواع مختلفة من المواد
- ✅ **رسوم بيانية حية** لمتابعة درجات الحرارة
- ✅ **تصدير البيانات** بصيغة JSON

## التقنيات المستخدمة

- **React 19** - مكتبة واجهة المستخدم
- **TypeScript** - لغة البرمجة
- **Tailwind CSS 4** - تصميم الواجهة
- **shadcn/ui** - مكونات UI جاهزة
- **Recharts** - الرسوم البيانية
- **Vite** - أداة البناء

## التثبيت والتشغيل

### المتطلبات

- Node.js 22.x أو أحدث
- pnpm (مدير الحزم)

### خطوات التشغيل

1. استنساخ المستودع:
```bash
git clone https://github.com/abdulrhmanalrimi/-FBD-120-.git
cd -FBD-120-
```

2. تثبيت التبعيات:
```bash
pnpm install
```

3. تشغيل المحاكاة:
```bash
pnpm dev
```

4. افتح المتصفح على: `http://localhost:3000`

## البناء للإنتاج

```bash
pnpm build
pnpm start
```

## الواجهات الرئيسية

### 1. Overview (نظرة عامة)
- عرض القيم الحالية (الحرارة، الضغط، السرعة)
- أزرار التحكم (Start, Stop, Emergency)
- حالة المعدات (السخانات، المؤقتات)
- الإحصائيات والعدادات

### 2. Visualization (التصور المرئي)
- رسم متحرك للآلة
- حركة الجزيئات والهواء
- توهج السخانات
- دوران المروحة

### 3. Settings (الإعدادات)
- ضبط معاملات العملية
- وصفات جاهزة
- وضع التحكم اليدوي

### 4. Alarms (الإنذارات)
- الإنذارات النشطة
- السجل التاريخي
- نظام الصوت التنبيهي

### 5. Trends (الرسوم البيانية)
- رسم بياني لدرجات الحرارة
- تحديث تلقائي كل 5 ثواني

## المواصفات التقنية

### المداخلات
- Temperature Setpoint: 40-100°C
- Drying Time: 10-60 دقيقة
- Cooling Time: 5-30 دقيقة
- Blower Speed: 30-100%

### المخرجات
- Product Temperature: 0-100°C
- Inlet Temperature: 0-200°C
- Outlet Temperature: 0-200°C
- Main Pressure: 0-6 bar
- Filter ΔP: 0-1000 Pa

## التوافق مع PLC

المحاكاة مبنية على منطق PLC حقيقي (Siemens S7-200) وتحاكي:
- مراحل التشغيل (Heating → Drying → Cooling)
- التحكم في السخانات بناءً على فرق درجة الحرارة
- نظام الأمان والإنذارات
- المؤقتات والعدادات
